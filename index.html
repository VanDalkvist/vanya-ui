2. <ThemeToggle />

import { ThemeToggle } from "@vanya/ui"

Контрол темы оформления с поддержкой двух вариантов рендера: variant="dropdown" (микро-иконка из Синусоиды) и variant="segmented" (капсула). Клик по демонстрационным кнопкам ниже переключает только внутреннее состояние демо-компонента (тему самой витрины переключает контрол в правом верхнем углу).

Вариант dropdown (Синусоида)
☀ иконка с выпадающим меню (3 режима)
Вариант segmented (капсула)
<ThemeToggle variant="dropdown" defaultTheme="system" />

3. <ActionButton />

import { ActionButton } from "@vanya/ui"

Кнопки без прямоугольных рамок (канон Синусоиды). Управление осуществляется чистой типографикой со сменой цвета на ховере.

<ActionButton variant="text" onClick={handleClick}>Войти в поток</ActionButton>

4. <Kbd />

import { Kbd } from "@vanya/ui"

Единственный интерактивный элемент с микро-рамкой. Отображает клавиатурную клавишу, поддерживает активное состояние lit.

← → навигация
N активная клавиша (lit)
Esc закрыть
<Kbd lit={isPressed}>N</Kbd>
