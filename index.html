@vanya/ui справочник компонентов · v0.1.0
1. Семантические токены OKLCH tokens.css
Единая палитра для темного угля и светлой архивной бумаги. Контрастность проверена по WCAG AA (≥ 4.5:1). Граница — ровно 10% прозрачности.
--ground
--surface
--surface-raised
--ink
--accent
2. <ActionButton /> import { ActionButton } from "@vanya/ui"
Кнопки без прямоугольных рамок (канон Синусоиды). Управление осуществляется чистой типографикой со сменой цвета на ховере.
<ActionButton variant="text" onClick={handleClick}>Войти в поток</ActionButton>
3. <Kbd /> import { Kbd } from "@vanya/ui"
Единственный интерактивный элемент с микро-рамкой. Отображает клавиатурную клавишу, поддерживает активное состояние lit.
← → навигация
N активная клавиша (lit)
Esc закрыть
<Kbd lit={isPressed}>N</Kbd>
4. <NavLinks /> & <Divider /> import { NavLinks, Divider } from "@vanya/ui"
Навигационный ряд из NowQuickLinks (Синусоида): бесшовные кнопки разделов с вертикальными разделителями и быстрым переходом к «Сейчас».
<NavLinks items={sections} nowLabel="Сейчас" onNowClick={handleJump} />
5. <CategoryBadge /> import { CategoryBadge } from "@vanya/ui"
Мягкие бесшовные теги категорий из Фермы (без грубых рамок).
# Creative # Infra # Life # Product
<CategoryBadge category="Creative" />
6. <SegmentedControl /> import { SegmentedControl } from "@vanya/ui"
Капсульный переключатель без внутренних рамок у кнопок. Используется для горизонтов (1d/7d/30d) и полок со счётчиками.
<SegmentedControl items={horizons} value={active} onChange={setActive} />
7. <RangeSlider /> import { RangeSlider } from "@vanya/ui"
Волосяной минималистичный слайдер зума/дистанции времени с янтарным бегунком.
дистанция: 42%
<RangeSlider label="дистанция" value={zoom} min={1} max={100} onChange={handleChange} />
8. <LinkChip /> & <Tag /> import { LinkChip, Tag } from "@vanya/ui"
Чипы источников со стрелкой ↗ и теги события из карточки события Синусоиды.
каналt.me/VanyAIShilo↗ репозиторийgithub.com/VanDalkvist↗ #созерцание #звук-d-dorian
<LinkChip url="https://t.me/channel" label="канал" />
9. <DisclosurePill /> import { DisclosurePill } from "@vanya/ui"
Инлайн-аппендикс без модальных окон (из EventAppendix). Раскрывает дополнительный текст по клику.
Подробности арки характера ▼
Инлайн-раскрытие заметок и ссылок без открытия тяжелых модальных окон.
<DisclosurePill title="Заметки">Содержимое</DisclosurePill>
10. <HearthPulse /> import { HearthPulse } from "@vanya/ui"
Тлеющий янтарный импульс активности очага с мягкой ping-анимацией.
очаг активен
<HearthPulse label="очаг активен" />
