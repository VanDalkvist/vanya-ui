# @vanya/ui

> Личная дизайн-система «Hearth & Wave» (Созерцательный крафтовый минимализм) для автономных сервисов и инструментов Вани Афанасова.

## Стек
- Tailwind CSS v4 (`@theme inline`)
- OKLCH цветовые шкалы (уголь, лён, янтарь, кармин)
- Шрифтовая триада: `Fraunces` + `Manrope` + `JetBrains Mono` (lowercase)
- Микро-радиусы: 2px и 4px

## Компоненты
- `CraftCard`: карточка на теплом угле с hairline-границей
- `MeshStatusBadge`: тихий статус сервисов
- `InspectDrawer`: правый инспектор с backdrop-blur
- `ReceiptDigestModal`: модальное окно книжной выжимки дня
- `ActionButton`: строгая кнопка с микро-радиусом 2px
- `OfferCard`: карточка варианта пути с оценкой по SDT
