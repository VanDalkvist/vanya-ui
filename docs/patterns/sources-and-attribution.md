# Источники, цитирование и лицензии материалов Vanya Arc / UI

**Область действия:** `docs/`, `README.md`, `.agents/`, содержимое витрины, LLM-справочники, примеры кода и внешние изображения. Сначала проверь права на конкретный **материал**, а не только наличие ссылки. Это редакционные правила, не юридическое заключение.

## Различай четыре способа использования

| Что делаем | Нужно перед публикацией |
| --- | --- |
| **Ссылаемся на факт, идею, UI-паттерн или норму** | Автор/организация, название, **прямая ссылка на первоисточник**, утверждение, которое он подтверждает; авторская интерпретация отдельно. Лицензия на копирование не требуется, пока чужое охраняемое выражение не воспроизводится |
| **Цитируем чужой текст дословно** | Видимое выделение цитаты, автор, название, точная ссылка/страница, цель цитирования и основание: разрешение/лицензия или применимое исключение; **объём только по цели**, не «до N слов можно всегда» |
| **Копируем или адаптируем CC BY 4.0 произведение** | Оригинальный правообладатель/автор, название, URL оригинала, **CC BY 4.0** и прямая ссылка на неё, уведомление об изменениях, сохранение требуемых исходных notices. Чужое содержимое не становится собственным MIT/CC BY материалом |
| **Встраиваем программный код, SVG, иконку, фотографию, шрифт, скриншот** | Точное происхождение, copyright holder, проверенная лицензия и требования; для MIT — copyright+полный текст; для OFL — условия при распространении шрифта; для брендового знака — отдельные правила, права и ограничения |

**Открытый URL и подпись «источник» не дают разрешения** на перепечатку книги, изображений, наборов скиллов или документации. Не следует механически перефразировать большие части чужого текста, чтобы избежать лицензии; это может сохранить узнаваемую охраняемую форму.

## Проверка цитирования по праву

Нет универсальной числовой нормы допустимого объёма цитаты. Для ЕС ст. 5(3)(d) [Директивы 2001/29/EC](https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=CELEX:32001L0029) допускает в национальном праве исключения для цитат (например, критика и обзор), если материал опубликован законно, указан автор/источник, цитирование добросовестно и объём оправдан целью. Проверяй действующий закон конкретной страны и назначение публикации. Для иллюстраций, необычно коротких оригинальных текстов, логотипов и длинных отрывков риск выше: получить разрешение либо ограничиться ссылкой и самостоятельной аналитикой.

## Обязательная карточка для ресёрча или LLM

При добавлении нового первоисточника фиксируй:

1. **Автор/организация**, **название**, **оригинальный URL** и дату проверки.
2. **Какой конкретный тезис подтверждает** ссылка. Не выдавать нашу гипотезу за позицию оригинала.
3. **Тип использования:** ссылка/пересказ факта; прямой фрагмент; перевод/адаптация; заимствованное изображение; код.
4. **Правовое основание:** `reference-only`, точная лицензия и её URL, письменное разрешение или конкретное ограниченное исключение. Если неизвестно — `rights-unverified`; **не копировать**.
5. **Для CC BY адаптации:** creator + title + source + license + changes; для MIT — исходное notice и текст лицензии.
6. **Риск:** право соавторов, чужие изображения/лицензии, AI-assisted оригинальность, юрисдикция, сходство чужих знаков.

## Примеры

**Авторская ссылка:** «В [Apple HIG Typography](https://developer.apple.com/design/human-interface-guidelines/typography) (Apple) описаны принципы типографической иерархии; выбранная шкала Vanya UI — наша реализация». Без чужих скриншотов и логотипов.

**CC BY 4.0 адаптация:** «[Название работы], [автор], [оригинал], [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Изменения: перевод и сокращение». Это пример **только когда исходная лицензия действительно CC BY**, а не для книги Ильяхова.

**Цитата:** «...», автор, название, страница/точный URL и причина цитирования; проверить пределы цитатного исключения или разрешение. По умолчанию выбирай ссылку + собственный пересказ.

## Приёмка для агента и редактора

Проверить прямой адрес в первоисточнике, соответствие тезису, лицензию оригинала, необходимость кавычек, границы дословного заимствования, изменение при адаптации, актуальность лицензионных заметок и публичную безопасность. При сомнении — **не публиковать скопированное содержимое**, оставить ссылку и отдельный вывод. Ограничение полноты проверки явно указывать.
