# Композиция: читающие дроверы и рабочие поверхности

Актуально на 22.11.2026. Переносимый контракт для панели с большим материалом, стадиями обработки и источниками. Пример в каталоге Vanya UI: `#composition-reading-inspector`. Пункт верхней навигации «Композиция» ведёт к нему, а не к декоративному первому экрану.

## Проблема, подтверждённая в Factory v3

Скриншот 22 ноября показал, что шапка отнимала больше половины окна: крупный chrome `Читать оригинал`, полноценный page title, отдельная инструкция о происхождении, несколько строк workflow, отдельная строка метаданных и `space-y` от Tailwind **одновременно** с CSS `gap`. Содержимое статьи начиналось только после 700+ px. Проблема компоновки и двойных отступов, а не просто размера отдельных элементов.

## Композиционный контракт (одна поверхность, четыре слоя)

1. **Inspector chrome.** Уже существующий `InspectDrawer` с названием действия и Close. Он единственный не прокручивается на обычной высоте. До 600 px по высоте сам `dialog` становится прокруткой, а chrome sticky **внутри него**, без второго scroll owner.
2. **SurfaceHeader** в потоке. `eyebrow/title/subtitle/actions`, компактный многострочный перенос. `collapseAnchor` — метка источника видимости для родительского `InspectDrawer` (никаких глобальных обработчиков `window.scroll`).
3. **WorkflowStrip** в потоке. Одна строка: процесс, текущая стадия, реальный прогресс, пауза/продолжение или переключение языка. Если не помещается, перенос **внутри одного блока**, не отдельная длинная шапка.
4. **InspectorMeta** — нативный `details`: источник, дата, кеш, ограничения извлечения, диагностика. Короткая строка видна всегда, полный текст раскрывается явно. **Ничего не удалено.**

Затем **сразу тело статьи**: предел строки 65–75ch, размер для чтения, отдельные стили для ссылок, цитат, кодовых блоков и таблиц. Не добавлять объяснений или вторичных CTA между состоянием и началом контента.

## Expanded → Compact без двух sticky панелей

`InspectDrawer.compactContext={{title,eyebrow,status,actions}}` переводит **исходный** `inspect-sheet__header` в компактное состояние после ухода из видимой области `SurfaceHeader[collapseAnchor]`. `IntersectionObserver` наблюдает anchor относительно **реального scroll owner** (обычно `.inspect-sheet__body`, при низкой высоте — `dialog`). Пока source heading виден, chrome не повторяет title. Когда он исчезает, тот же chrome заменяет «Читать оригинал» на контекст материала. Close остаётся на месте. Не добавлять поверх него `StickyContextBar`.

На мобильной ширине убирать декоративное, но не Close и обязательные команды. Повторная компоновка работает с `overflow-wrap`, адаптивным переносом и 200% zoom. В плашке действий только важные команды; технические метаданные не закрепляются.

**Запрет на двойные вертикальные отступы:** когда дочерняя обёртка уже использует `display:flex; flex-direction:column; gap:N`, **не совмещать `space-y` с `gap`**, а использовать только одну модель вертикального ритма. В Tailwind v4 `space-y` задаёт `margin-block-end` у всех прямых детей, кроме последнего (а не прежний `margin-top`). Если в уже существующем компоненте нельзя убрать `space-y`, временный сброс должен включать **обе стороны**: `> :not(:last-child) { margin-block-end: 0 }` и `> * + * { margin-block-start: 0 }`. Иначе каждый интервал становится `gap + margin`; это главный баг со скриншота.

## Варианты применения

- **Source Reader:** `SurfaceHeader` содержит publisher/title/links, `WorkflowStrip` — перевод + стадии, `InspectorMeta` — Exa/retrieval/provenance.
- **Evidence Inspector:** `SurfaceHeader` — факт/происхождение, `WorkflowStrip` — проверка, `InspectorMeta` — источники/качество.
- **Publish Inspector:** `SurfaceHeader` — канал/пост, `WorkflowStrip` — статус доставки, `InspectorMeta` — attempt IDs, provenance, timestamps.

Эти компоненты не привязаны к D1, Exa, OpenRouter, Factory, конкретным endpoint или юридическим текстам. Продукт контролирует данные и actions.

## Проверяемые правила

- Начало тела читается на первом экране 900px, даже когда workflow выполняется.
- В узком окне основное действие и Close доступны без горизонтального переполнения.
- Один вертикальный scroll owner; sticky chrome не перекрывает таб-фокус.
- Полное название не видно сразу в двух заголовках: title переходит в chrome после ухода in-flow identity.
- Ошибки, прогресс и пауза продолжают работать независимо от прокрутки.
- Метаданные и пояснения доступны через раскрытие, но не затмевают статью.
- Встроенная панель не копирует внешний сайт целиком: владелец продукта отвечает за source и права.

## Исследовательская база

- [NN/g Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/) — частые действия сразу, пояснения по запросу.

## Стоимость действий на месте

`CostIndicator` — компактный семантический элемент для стоимости рядом с конкретным вызовом (Exa, перевод, AI-проверка) и в общем статусе без дублирующих больших карточек. Значения должны приходить из биллинга/учёта, а не из выдуманной цены в интерфейсе. `usd={null}` означает «Стоимость неизвестна» — не `$0`. `certainty` различает measured/estimated/free/unknown, а `cached` показывает, что нового запроса не было. Для набора стадий стоимость берётся из сохранённых событий и указывается отдельно от цены нового шага.

Проверяемая реализация: [Tailwind v4 — space-between selector](https://tailwindcss.com/docs/upgrade-guide#space-between-selector). В Factory был именно двойной вертикальный отступ: `space-y-5` плюс `gap`. Регрессионный тест должен покрывать **`margin-block-end`**, не только `margin-block-start`.
