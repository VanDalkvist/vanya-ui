Primary reference routing already recorded in design-reference-canon-2026-11-27.md: Linear (calm visual hierarchy, predictable alignment); Apple HIG layout (group related information, preserve hierarchy and adapt); shadcn/ui (reusable anatomy and real examples). Specific local grid proposal is an interpretation, not upstream exact geometry.

Proposed common documentation/workspace grammar:
1. One chapter header H2 and short introduction above all content. Existing overview hero H1 retains product purpose.
2. A shared private documentation row primitive (evolve CatalogSection or extract a shared shell) with left heading/description and right actual example, explanatory content or reference. One shared CSS grid, breakpoint, divider, section spacing, heading typography and reading-measure policy. Both columns top-align; repeated right axes line up across chapters. Use actual width/token measurements before choosing ratios.
3. Content that needs full width (wide graph, logo specimen, side-by-side bilingual reading or before/after comparison) gets an intentional full-width specimen within that same row grammar; maintain sufficient space and shared leading axis. No empty right column for prose-only rule: place actual detailed guidance or reference there, or use one reading column when useful. No decorative numbers or forced filler.
4. Identity: group parent/UI comparison, color/theme modes, construction rules, palette. Typography: shared row grid for scale/tracking/reading specimens; nested comparisons only where comparison is the task. Writing: left explains the editorial rule, right shows example or source list. Principles: left states rule, right shows paths, concrete guidance or reference; avoid duplicating title/description. Agents/setup: left labels task, right provides prompt, commands or resources. Components/workspaces use existing interactive content within the shared shell.
5. Mobile stack heading/description before specimen, preserve focus order, anchors, sticky header offset, no overflow at 320/390 and 200% zoom. Preserve readable text measure and enough specimen width. Light/dark. Avoid arbitrary equal-sized panels, nested scroll and separate CSS per chapter.
